# NOTE changes to the vendored esp32sim

Upstream: https://github.com/joakimeriksson/esp32sim at
`4ab7e900fee998d0137c2c57d59de9d05339d093` (2026-09-23, MIT). Imported unmodified on
2026-09-27; upstream's hermetic + golden suite passes on the reference Mac with the imported
esp-rom-elfs 20241011 ROM.

Every change below lists its work package (proposal §4), files, rationale and the fixture or
test that proves it. Run the upstream suite after each change:

```sh
# The goldens need the S3, C3 and C6 ROM ELFs, so point at a full esp-rom-elfs release
# (the NOTE ROM store holds only the S3 one).
ESP32SIM_ROM_DIR=<esp-rom-elfs 20241011 directory> \
  cargo test --release --workspace -- --include-ignored --skip external_
```

Last full run: 2026-09-28 after #12 and the G7 snapshot hooks, **499 passed, 0 failed**, `--skip external_`. Goldens included and stayed bit-identical. Earlier separate runs passed 491 after NET-04 and 490 after AP+STA.
